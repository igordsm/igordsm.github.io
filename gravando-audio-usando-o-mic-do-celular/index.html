Gravando áudio usando o mic do celular

janeiro 3, 2025 Igor Montagner
tech

Meu celular tem um microfone melhor que tanto meu notebook quanto a minha câmera USB. Como estou explorando gravar alguns vídeos explicativos resolvi tentar usá-lo para gravar as narrações.

Das últimas vezes gravei com outros microfones e acabei sempre precisando editar os áudios pois o volume ficava meio estranho, parecendo meio baixo e com um ruído de fundo incômodo. Vídeos gravados no celular não ficam assim e com uma qualidade bem melhor.

O scrcpy é um software que usa o ADB (Android Debug Bridge) para redirecionar a tela e/ou áudio do celular para o PC. Funciona incrivelmente bem, é rápido e permite também capturar os vídeos e áudios.

Para usá-lo é necessário ativar as opções de desenvolvimento e permitir debugging via USB. Com isso ativado é só rodar:

scrcpy --no-video  --audio-source=mic --record=bla.opus

Assim que acabar de gravar o áudio é só fechar o programa com Ctrl+C e pronto! Áudio gravado :) Prefiro usar assim pois posso posicionar o celular como um microfone “de verdade” e o áudio já fica gravado no PC. Não precisa ficar transferindo via cabo ou colocar em algum serviço de arquivos em Nuvem. Acho essa opção super prática e recomendo :)
